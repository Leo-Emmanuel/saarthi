## Suggested Demo Flow

1. Login as admin or teacher.
2. Create/upload `Demo MCQ Exam` using `mcq_demo_exam.docx`.
3. Login as a student and take the MCQ exam.
4. Show voice answer selection, review screen, submission, grading, teacher dashboard, and CSV export.
5. Create/upload `Demo Written Maths Exam` using `maths_written_demo_exam.docx`.
6. Login as a student and take the maths exam.
7. Show voice-to-math dictation, answer playback/review, submission, teacher evaluation, and CSV export.

Note: For the written maths paper, auto-grading may be more sensitive because it uses similarity scoring. If a score is imperfect, use it as a good moment to show the teacher evaluation/manual grading feature.
